## 🔧 세부 기술 스택 및 활용 경험

실무에서 직접 활용한 네이티브 iOS 개발 기술과 개인 프로젝트에서 AI 코딩 도구를 활용해 적용한 기술을 구분하여 정리했습니다.

**숙련도 기준**
- **상:** 실무에서 독립적인 기능 개발, 문제 해결 및 구조 개선 가능
- **중:** 주요 개념을 이해하고 기능 구현 및 유지보수 경험 보유
- **하:** 기초적인 활용 경험 또는 AI 코딩 도구를 중심으로 구현한 경험 보유

### 1. 📱 iOS 개발

#### Swift
- **사용 기간:** 3~5년
- **숙련도:** 상
- **세부사항:** Swift 기반 iOS 금융 서비스 개발 및 유지보수. 국내외 송금, 페이 충전, 오픈뱅킹, 회원가입·본인인증 등 주요 기능 구현. 비동기 네트워크 통신 및 공통 모듈 설계 경험.

#### Objective-C
- **사용 기간:** 3~5년
- **숙련도:** 상
- **세부사항:** Objective-C 기반 레거시 iOS 앱 유지보수 및 기능 개선. Swift와 혼용된 프로젝트 환경에서 기존 모듈 분석, 기능 수정 및 신규 기능 연동 수행.

#### UIKit
- **사용 기간:** 3~5년
- **숙련도:** 상
- **세부사항:** UIKit 기반 iOS 화면 및 사용자 인터랙션 구현. 회원가입·로그인, 송금, 페이 충전 등 복잡한 화면 흐름 개발. SnapKit을 활용한 Auto Layout 및 재사용 가능한 UI 컴포넌트 구성.

#### RxSwift
- **사용 기간:** 3~5년
- **숙련도:** 상
- **세부사항:** RxSwift 기반 비동기 네트워크 처리 및 이벤트 스트림 관리. 다중 API 병렬 처리, UI 이벤트 바인딩 및 MVVM 패턴을 활용한 화면 상태와 비즈니스 로직 분리 경험.

#### SwiftUI
- **사용 기간:** 1년 미만
- **숙련도:** 중
- **세부사항:** SwiftUI의 선언형 UI 구조와 상태 관리 방식에 대한 이해를 바탕으로 화면 구현 경험 보유. UIKit 기반 개발 경험을 활용한 SwiftUI 학습 및 적용.

#### Alamofire
- **사용 기간:** 3~5년
- **숙련도:** 상
- **세부사항:** REST API 기반 서버 통신 및 네트워크 계층 구현. 공통 요청·응답 처리, 오류 처리 및 API 연동 경험. 기존 SOAP/REST 통신 구조 리팩토링 수행.

#### SnapKit
- **사용 기간:** 3~5년
- **숙련도:** 상
- **세부사항:** SnapKit을 활용한 코드 기반 Auto Layout 구현. 다양한 화면 크기에 대응하는 UI 구성 및 재사용 가능한 레이아웃 설계 경험.

### 2. 🏗️ 아키텍처 및 설계

#### MVVM (Model-View-ViewModel)
- **사용 기간:** 1~3년
- **숙련도:** 상
- **세부사항:** MVVM 아키텍처 기반 화면 로직과 비즈니스 로직 분리. Service, Provider, DTO 등 역할별 계층 설계 및 공통 모듈화를 통한 코드 재사용성과 유지보수성 개선. 아키텍처 가이드 수립 경험.

### 3. 🔄 크로스플랫폼 개발

#### React Native
- **사용 기간:** 1년 미만
- **숙련도:** 하
- **세부사항:** Codex 등 AI 코딩 도구를 활용하여 React Native 및 Expo 기반 모바일 앱 개발. 학습 콘텐츠, 사용자별 학습 상태 관리 및 Firebase 연동 기능 구현. EAS Build와 EAS Update를 활용한 앱 빌드·배포 및 실제 스토어 출시 경험.

#### TypeScript
- **사용 기간:** 1년 미만
- **숙련도:** 하
- **세부사항:** AI 코딩 도구를 활용한 React Native 프로젝트에서 TypeScript 적용. 컴포넌트, 데이터 모델 및 상태 관리 코드의 구조를 검토하고 기능 수정과 오류 해결에 활용.

### 4. 🗄️ 백엔드 및 데이터베이스

- **사용 기간:** 1년 미만
- **숙련도:** 하

#### PHP
- **사용 기간:** 1~3년
- **숙련도:** 중

#### MySQL
- **사용 기간:** 1~3년
- **숙련도:** 중
